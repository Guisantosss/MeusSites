# MeusSites

Sites publicados pelo GitHub Pages. Cada pasta com `package.json` é um site: a cada envio para a branch `main`,
o GitHub Actions (`.github/workflows/deploy.yml`) monta todos e publica em
`https://guisantosss.github.io/MeusSites/<pasta>/`.
